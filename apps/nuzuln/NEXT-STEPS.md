# إكمال تطبيق «نزلاً» — ما بقي عليك

الكودُ جاهز: التطبيق يُبنى (`app-debug.apk`) واختباراته الـ26 ناجحة. بقيت ست خطوات، **بهذا الترتيب**.
كلُّ خطوةٍ تنتهي بسطر «تمّت حين…» لتعرف أنها اكتملت.

| # | الخطوة | إلزامية؟ | الوقت التقريبي |
|---|---|---|---|
| 1 | تفعيل الإشعارات (Firebase) | نعم — وإلا لا يصل وليَّ الأمر إشعار | 15 دقيقة |
| 2 | التجربة على جهاز | نعم | 30 دقيقة |
| 3 | حذف التطبيقات الثلاثة القديمة | نعم | 10 دقائق |
| 4 | تنظيف التوثيق بعد الحذف | نعم | 5 دقائق |
| 5 | التصدير والتوزيع | نعم | 10 دقائق |
| 6 | مفتاح التوقيع قبل المتجر | قبل Google Play فقط | 15 دقيقة |

## 1. تفعيل الإشعارات (Firebase)

**لماذا:** ملفُّ `google-services.json` الحالي مسجَّلٌ لتطبيق ولي الأمر القديم (`sy.mousqe.mousqe_guardian`)،
والتطبيق الجديد اسمُه `com.timeofcode.nuzuln`. حتى تُنجز هذه الخطوة يعمل التطبيق كاملاً **لكن بلا إشعارات**.

**الخادم لا يتغيّر:** المشروعُ نفسُه (`mousqe`)، فمفتاحُ الخدمة الذي يرسل به الخادمُ الإشعارات يبقى صالحاً.

1. ثبّت الأداتين (مرّةً واحدة على حاسوبك، وتحتاج Node.js):

   ```powershell
   npm install -g firebase-tools
   dart pub global activate flutterfire_cli
   firebase login
   ```

2. سجّل التطبيق الجديد واكتب ملفّاته:

   ```powershell
   cd apps/nuzuln
   flutterfire configure --project=mousqe --platforms=android --android-package-name=com.timeofcode.nuzuln
   ```

   الأمر يضيف تطبيق أندرويد `com.timeofcode.nuzuln` في مشروع Firebase، ويكتب
   `android/app/google-services.json`، ويجدّد `lib/firebase_options.dart`.

3. احذف السطرين اللذين أضفتُهما أعلى `lib/firebase_options.dart` إن بقيا (يبدآن بـ`// Copied from apps/guardian`).

4. لا تعدّل Gradle: ملحق `google-services` يُطبَّق تلقائياً متى وُجد الملف.

**تمّت حين:** يحوي `apps/nuzuln/android/app/google-services.json` النصّ `com.timeofcode.nuzuln`، و`flutter build apk --debug` ينجح.

## 2. التجربة على جهاز

1. شغّل الخادم ببياناتٍ تجريبية جديدة:

   ```powershell
   cd backend
   php artisan migrate:fresh --seed
   php artisan serve --host=0.0.0.0 --port=8000
   ```

2. احصل على حسابات التجربة: ادخل اللوحة بـ`admin1000` وكلمة المرور `password`، ثم افتح صفحة
   **«بيانات الدخول»** (`/credentials`) وانسخ حساب أستاذ وولي أمر وطالب **من نفس الحلقة**.

3. شغّل التطبيق:

   ```powershell
   cd apps/nuzuln
   flutter run
   ```

   - **على المحاكي:** يتّصل بالحاسوب تلقائياً (`10.0.2.2:8000`).
   - **على هاتف حقيقي:** انقر الشعار في شاشة البدء **ثلاث مرّات** واختر «خادم محلّي»، ثم أدخل عنوان
     حاسوبك في الشبكة (مثل `192.168.1.10:8000`).

4. نفّذ هذه السيناريوهات **على الجهاز نفسه وبالترتيب**:

   | # | افعل | المتوقَّع |
   |---|---|---|
   | 1 | ادخل بحساب **الطالب** | تفتح رئيسية الطالب: رتبته ونسبته ونقاطه. **لا** يُسأل عن إذن الإشعارات |
   | 2 | اخرج، ثم ادخل بحساب **ولي الأمر** | تفتح «أبنائي» وفيها الطالب نفسه. **يُسأل** عن إذن الإشعارات، فوافق |
   | 3 | قدّم إذن غياب للابن | يظهر في «الأعذار» بحالة «معلّق» |
   | 4 | من اللوحة: اقبل الإذن | **يصل إشعارٌ** للهاتف (يحتاج الخطوة 1) |
   | 5 | اخرج، ثم ادخل بحساب **الأستاذ** | تفتح «حلقاتي»، ولا يظهر شيءٌ من بيانات ولي الأمر |
   | 6 | **أطفئ الشبكة**، وافتح جلسة وسجّل التفقّد | يُحفظ التفقّد ويظهر عدّاد «بانتظار المزامنة» |
   | 7 | أعد الشبكة | يُزامَن تلقائياً، ويظهر التفقّد في اللوحة |
   | 8 | سجّل الخروج والشبكة مطفأة وفيه تفقّدٌ معلّق | يحذّرك: «ما زالت N عملية بانتظار المزامنة» |
   | 9 | ادخل بـ`admin1000` | يرفض: «حسابات الإدارة تدخل من تطبيق الإدارة» |

**تمّت حين:** نجحت السيناريوهات التسعة. إن فشل أحدُها فأرسل لي رقمَه وما ظهر لك.

## 3. حذف التطبيقات الثلاثة القديمة

افعلها **بعد** نجاح الخطوة 2 فقط.

1. احذف المجلّدات:

   ```powershell
   git rm -r apps/teacher apps/guardian apps/student
   ```

2. في [`pubspec.yaml`](../../pubspec.yaml) (جذر المستودع) احذف من `workspace:` هذه الأسطر الثلاثة:

   ```yaml
     - apps/guardian
     - apps/student
     - apps/teacher
   ```

3. في [`scripts/export-apps.ps1`](../../scripts/export-apps.ps1):
   - احذف من مصفوفة `$apps` سطور `teacher` و`guardian` و`student`.
   - احذف أسطرها الثلاثة من قسم `.DESCRIPTION` أعلى الملف.
   - عدّل قائمة `.PARAMETER Only` لتصير: `mobile, admin_desktop, admin_android`.

4. في [`scripts/build-app-icons.py`](../../scripts/build-app-icons.py) اجعل السطر:

   ```python
   for app in ('nuzuln', 'admin_desktop'):
   ```

5. حدّث الاعتماديات وتأكّد أن كلَّ شيءٍ سليم:

   ```powershell
   flutter pub get
   melos run analyze
   melos run test
   ```

**تمّت حين:** ينجح `melos run analyze` و`melos run test` بلا أخطاء.

## 5. التصدير والتوزيع

1. صدّر النسخة (بيتا):

   ```powershell
   .\scripts\export-apps.ps1 -Notes 'دمج تطبيقات الأستاذ وولي الأمر والطالب في تطبيق نزلاً واحد'
   ```

   إن لم تكن نفّذت الخطوة 3 بعد، فحدّد التطبيقات صراحةً حتى لا تخرج القديمة معها:
   `-Only mobile,admin_desktop,admin_android`

2. **أبلغ المستخدمين الحاليين قبل التوزيع** — التطبيق الجديد له معرّفٌ مختلف، فيُثبَّت **بجانب** القديم لا فوقه،
   ولا تنتقل إليه بيانات القديم:
   - **الأساتذة أوّلاً:** افتحوا «نزلاً · الأستاذ» القديم **وهم متّصلون**، وتأكّدوا أن عدّاد المزامنة صفر،
     ثم احذفوه. وإلا ضاع ما لم يُزامَن.
   - **الجميع:** ثبّتوا «نزلاً» الجديد، وادخلوا بالاسم وكلمة المرور نفسيهما، ثم احذفوا التطبيق القديم.
   - **المشرفون:** تطبيقُ الإدارة على أندرويد تغيّر معرّفُه أيضاً (`com.timeofcode.nuzuln.admin`)، فيُثبَّت بجانب
     القديم. زامِنوا القديمَ حتى يصير الطابورُ صفراً، ثم احذفوه وثبّتوا الجديد. نسخةُ ويندوز لا تتأثّر.

**تمّت حين:** يظهر الإصدار الجديد في رأس قسم البيتا في `VERSION.md`، وفي `dist/` ملفُّ `nuzuln-mobile-….apk`.

## 6. مفتاح التوقيع (قبل Google Play فقط)

كلُّ التطبيقات اليوم تُوقَّع بمفتاح التطوير (`signingConfigs.getByName("debug")`). يكفي للتوزيع المباشر
بملفّ APK، **ولا يقبله Google Play**. وبعد أوّل رفعٍ للمتجر لا يتغيّر المفتاح ولا `com.timeofcode.nuzuln` أبداً.

1. أنشئ المفتاح واحفظه **خارج المستودع** مع نسخةٍ احتياطية:

   ```powershell
   keytool -genkey -v -keystore $HOME\nuzuln-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```

2. أنشئ `apps/nuzuln/android/key.properties` (وتأكّد أنه في `.gitignore`):

   ```properties
   storePassword=…
   keyPassword=…
   keyAlias=upload
   storeFile=C:/Users/<اسمك>/nuzuln-upload.jks
   ```

3. اطلب منّي ربطه في `build.gradle.kts` — هو تعديلٌ صغير، والأسلم أن أكتبه وأختبره بالبناء.

**تمّت حين:** `flutter build appbundle --release` ينجح ويُوقَّع بمفتاحك.
