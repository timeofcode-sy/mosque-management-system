# إصدارات نزلاً

رقمٌ واحد للنظام كلّه: التطبيقان («نزلاً» للهاتف: الأستاذ · ولي الأمر · الطالب، والإدارة: ويندوز وأندرويد) يخرجان معاً بنفس
الإصدار ونفس رقم البناء.

**لا يُحرَّر هذا الملفُّ باليد إلا في نصّ «أبرز التغييرات».** يحدّثه
[`scripts/export-apps.ps1`](../scripts/export-apps.ps1) عند كل تصدير: يحسب الرقمَ التالي، ويبني، ثم
يضيف المدخلَ في رأس قسمه — **ولا يكتب شيئاً إن فشل بناءُ أيِّ تطبيق**، فكلُّ رقمٍ هنا نسخةٌ خرجت فعلاً.

| | القاعدة |
|---|---|
| **الإصدار** `X.Y.Z` | نسخةٌ نهائية للمستخدمين. إن سبقتها بيتا تأخذ رقمَها (`1.1.0-beta.3` ← `1.1.0`)، وإلا يُرفع الرقم بحسب `-Bump` |
| **البيتا** `X.Y.Z-beta.N` | نسخةُ تجربة قبل الإصدار. تتتابع على نفس الرقم (`beta.1` ← `beta.2`) حتى يخرج إصدارُه، ثم تبدأ دورةٌ جديدة |
| **رقم البناء** `build` | عدّادٌ واحد يزيد مع كل نسخة — بيتا كانت أو إصداراً. أندرويد لا يثبّت نسخةً فوق أخرى أعلى منها رقماً |
